# ESP32-PinLab 使用说明

无线串口 + 引脚测试工具。PC 通过 WiFi 连上 ESP32-C3，就能把它当无线串口线用，
并且可以随时改引脚功能（ADC / PWM / 输出 / 输入），不用重新编译烧录。

**作者：Muchen（林慕辰）**

**本次版本：固件 `wbd_v1.3.0`　PC 端 `v1.3.0`**

---

## 一、包内文件

```
发布版/
├── ESP32-PinLab/             ← PC 端程序目录（双击里面的 exe 运行）
│   ├── ESP32-PinLab.exe      ←   主程序
│   └── _internal/            ←   运行库（别删，别单独挪走 exe）
├── ESP32-PinLab.zip          ← 上面整个目录的压缩包（分发给别人用这个）
├── ESP-update/
│   ├── firmware.bin          ← 固件（应用程序）
│   ├── bootloader.bin        ← 引导程序
│   ├── partitions.bin        ← 分区表
│   ├── 配置.png              ← 烧录工具的配置截图（照这个填）
│   └── ESP烧录工具.zip       ← 烧录工具（解压即用）
└── README.md                 ← 本文件
```

### ⚠️ 为什么是文件夹而不是单个 exe？

以前是单个 exe，但那种模式（PyInstaller `onefile`）在启动时会把自身解压到系统临时目录，
并且**需要创建符号链接**——而 Windows 默认**只有管理员或开启了「开发者模式」的用户**
才允许创建符号链接。普通账号运行时会报错：

```
Failed to extract _amd64.pyd: failed to read data chunk!
Failed to create symbolic link _amd64.pyd!
```

**这不是文件损坏，是权限问题。** 改成文件夹模式后：不需解压、不需符号链接、
启动更快，也不容易被杀毒软件误报。

> **使用时注意**：`ESP32-PinLab.exe` 和 `_internal\` 目录**必须放在一起**，
> 不能只把 exe 单独复制出来。要发给别人就发 `ESP32-PinLab.zip`。

> 固件也可以直接用 PlatformIO 命令行烧录，见第四节。

## 二、第一次使用（三步）

### 第 1 步：烧录固件

用 `ESP-update/ESP烧录工具.zip` 里的工具，按 `ESP-update/配置.png` 的设置烧录。

### 第 2 步：手机或电脑连上设备热点配网

固件**出厂不带任何 WiFi 信息**，烧完首次上电会自己开一个热点：

| 项目 | 值 |
|---|---|
| 热点名 | `Muchen_PinLab-xxxx`（xxxx 是设备 MAC 后 4 位） |
| 密码 | 无（开放热点） |
| 配网网址 | http://192.168.4.1/ |

用手机或电脑连上这个热点，浏览器打开 **http://192.168.4.1/** ，填入你家/公司的
WiFi 名称和密码，点「保存并连接」。

> 💡 **不用手打 WiFi 名！** 页面上有 **「扫描附近 WiFi」** 按钮，
> 点一下会列出周围所有网络（按信号强弱排序），**点一行就自动填好 SSID**，
> 再输密码即可。这样能避免手打错名字导致连不上。

> ⏱ **注意**：热点只在**没人连接**时倒数 2 分钟，到点设备会自动关机省电。
> 只要你连上了热点，就不会关机，可以慢慢填。

### 第 3 步：跑 PC 程序

电脑连回同一个 WiFi，双击 `ESP32-PinLab\ESP32-PinLab.exe`，程序会自动扫到设备。

> 嫌文件夹麻烦的话，把 `ESP32-PinLab.zip` 解压到任意位置再运行也一样。
> 记得整个文件夹一起用，别只复制 exe。

## 三、PC 程序怎么用

主界面左边是设备列表，右边是功能区。

| 操作 | 说明 |
|---|---|
| **双击设备** | 刷新该设备的配置和引脚占用 |
| **无线串口** | 打开串口收发窗口，像 USB 转串口一样用 |
| **配置** | 设置串口引脚（默认 TX=GPIO4、RX=GPIO5）并启用 |
| **释放** | 关掉串口、归还引脚，让 ADC / PWM 等功能可以用这两个脚 |
| **引脚控制** | 选 ADC / PWM / 输出控制 / 输入检测，各自独立窗口 |
| **STA / AP 开关** | 切换设备工作模式（见第五节） |
| **关于** | 显示版本、项目地址、固件下载链接和收款码 |

### 引脚占用规则

同一根引脚同时只能被一个功能占用，界面会自动灰掉已占用的脚。
如果某个脚选了不能用，程序会提示原因（例如 GPIO12/13 是板载双灯、
RTC 引脚在深度休眠时才有特殊行为等）。

## 四、固件怎么烧（两种方式）

### 方式 A：图形化工具（推荐）

1. 解压 `ESP-update/ESP烧录工具.zip`
2. 按 `ESP-update/配置.png` 的截图填好参数
3. 选好串口（COM 号）→ 点「开始」

`配置.png` 里的关键项：

| 文件 | 烧录地址 | SPI MODE | 波特率 |
|---|---|---|---|
| `bootloader.bin` | `0x0000` | DIO | 921600 |
| `partitions.bin` | `0x8000` | DIO | 921600 |
| `firmware.bin` | `0x10000` | DIO | 921600 |

> ### ⚠️ SPI MODE 一定要选 DIO，不要选 QIO
>
> 截图里那一栏**可能显示成 QIO**，请手动改成 **DIO** 再烧。
>
> 原因：ESP32-C3 的 **GPIO12 = SPIHD、GPIO13 = SPIWP**，而这块板子的
> **板载双灯正好接在这两个脚上**。只有在 DIO / DOUT 模式下这两个脚才是空闲的；
> 一旦用 QIO，Flash 会征用它们 →
> 轻则读写错误、板载灯乱闪，重则**直接无法启动**。
>
> 本固件已按 DIO 编译（已核对 `firmware.bin` 头部标志位 = DIO），
> 所以工具里的这一项必须与它一致。

### 方式 B：PlatformIO 命令行

```bash
cd esp32

# 首次烧录（或换过分区表）必须先全片擦除
pio run -e esp32c3 -t erase
pio run -e esp32c3 -t upload --upload-port COM6

# 之后只是升级固件，可以不擦除（保留已配好的 WiFi）
pio run -e esp32c3 -t upload --upload-port COM6
```

> ⚠️ 执行 `-t erase` 会清掉设备里保存的 WiFi 信息，设备会回到「开热点等配网」状态。

## 五、STA / AP 两种工作模式

设备有两种模式，可以在 **PC 程序的「STA / AP」开关** 或 **配网网页** 上切换。

| 模式 | 用途 | 设备 IP |
|---|---|---|
| **STA**（默认） | 设备连你家路由器，电脑和设备在同一网络里正常使用 | 由路由器分配 |
| **AP** | 设备自己开热点 `Muchen_PinLab-xxxx`，电脑直连它 | 固定 `192.168.4.1` |

**什么时候用 AP 模式？** 现场没有可用 WiFi 时，让电脑直接连设备。

> ⚠️ 切换模式后设备 IP 会变，PC 列表里可能短暂离线，之后会自己重新出现。
> 切到 AP 模式后，需要把电脑的 WiFi 连到 `Muchen_PinLab-xxxx` 才能继续控制它。

**STA 模式下连不上路由器会怎样？**
设备会自动开 2 分钟热点兜底；如果一直没人连，就自动关机省电。
按板上 **EN/RST** 键或拔插 USB 可重新开机。

## 六、常见问题

**1. PC 扫不到设备**
- 确认电脑和设备在**同一个网段**（路由器下连同一个 WiFi）
- 防火墙放行 **UDP 18665 / TCP 18666 / TCP 18667**
- 还不行就点「添加IP」，手动填设备 IP（AP 模式下固定是 `192.168.4.1`）

**2. 设备自己关机了**
这是省电设计：热点没人连着超过 2 分钟就关机。
重新开机：按板上 **EN/RST** 键，或拔插 USB。

**3. 热点连不上**
- 热点是**开放网络**（无密码），注意别被系统当成不安全网络拦掉
- 如果 `192.168.4.1` 和你的网络冲突，可以改用 STA 模式

**4. 连上了但用不了功能**
设备端启用了认证：必须用配套的 `ESP32-PinLab.exe`，固件和程序是**配套版本**，
不能混用旧版程序配新版固件。

**5. 串口收发乱码**
检查波特率是否和设备一致（默认 `115200`），以及 TX/RX 是否接反。

**6. 双击 exe 报 `Failed to extract _xxx.pyd` / `Failed to create symbolic link`**
说明你拿到的是**旧版的单个 exe**。那个版本需要管理员权限才能启动。
请改用本包里的 `ESP32-PinLab\` 文件夹（或解压 `ESP32-PinLab.zip`），
文件夹版没有这个限制。详见第一节的说明。

**7. 提示找不到 `_internal` 或缺少 DLL**
你把 `ESP32-PinLab.exe` 单独复制出来了。请连 `_internal\` 目录一起复制。

## 七、注意事项

- **固件与 PC 程序必须配套使用**。本次是 `wbd_v1.3.0` + `v1.3.0`，
  用旧版程序连新版固件会认证失败。
- 设备的串口引脚默认是 **GPIO4(TX) / GPIO5(RX)**，可在 PC 程序里改。
- 不要把串口接到 **GPIO12 / GPIO13**，那是板载双灯的脚。
- 供电不足会导致 WiFi 不稳定，建议用质量好一点的 USB 线。
